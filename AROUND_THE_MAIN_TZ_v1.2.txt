31. MOBILE EDITION — PAGE LAYOUT STANDARD

Mobile Edition является постраничным представлением одного Edition.

PUBLICATION MODEL:
- AROUND THE MAIN публикует 3 EDITIONS DAILY;
- технически система продолжает использовать три внутренних release slots;
- внутренние release slots работают по времени America/New_York:
  07:00;
  13:00;
  20:00;
- эти времена используются только production logic, watchdog, Editorial Snapshot, retry/recovery, idempotency и persistent delivery state;
- внутреннее время выпуска НЕ является публичной частью визуальной идентичности Edition.

PUBLIC VISUAL IDENTITY:
- публичная концепция:
  3 EDITIONS DAILY;
- публичный дизайн НЕ должен отображать:
  07:00;
  13:00;
  20:00;
  Morning Briefing;
  Midday Update;
  Evening Round-up;
- публичная идентификация Edition строится через:
  EDITION XXXX;
  publication date;
  PAGE XX;
- задержка технической публикации не должна менять публичную идентичность Edition;
- номер Edition определяется существующей системой нумерации и не должен зависеть от фактического времени отправки.

PAGE 01:
- использует единый branded header image:
  assets/mobile-header.png;
- отдельный logo.png в верхней части страницы НЕ используется;
- header содержит фирменную визуальную идентичность AROUND THE MAIN;
- header НЕ должен содержать встроенное название времени суток / daypart;
- после header отображаются:
  EDITION XXXX;
  publication date;
  PAGE 01;
- после информационного блока начинается контент выпуска;
- в нижней части страницы располагается обновлённый public footer;
- footer должен визуально поддерживать концепцию:
  3 EDITIONS DAILY.

PAGES 02+:
- branded header image НЕ используется;
- отдельный logo НЕ используется;
- в верхней части располагается компактная строка с нейтральной идентификацией Edition;
- PAGE XX располагается справа;
- под строкой располагается горизонтальный divider;
- далее располагается контент страницы;
- в нижней части каждой страницы располагается единый public footer;
- названия Morning Briefing / Midday Update / Evening Round-up НЕ используются.

PAGE NUMBER:
- номер страницы формируется динамически;
- формат:
  PAGE 01
  PAGE 02
  PAGE 03
  ...;
- номер страницы не должен быть задан глобальной переменной;
- каждая страница должна получать собственный page_number.

EDITION NAME:
- публичное название Edition по времени суток НЕ используется;
- функции внутреннего определения release slot могут сохраняться в production code;
- внутренний release slot не должен автоматически превращаться в публичный daypart label.

FOOTER:
- footer должен быть единообразным на всех страницах Mobile Edition;
- footer располагается в нижней части страницы;
- Page 01 footer должен визуально содержать основной product message:
  3 EDITIONS DAILY;
- footer может сохранять утверждённые элементы AROUND THE MAIN, включая branding, support/contact elements и social/channel references;
- footer НЕ должен содержать:
  07:00;
  13:00;
  20:00;
  Morning Briefing;
  Midday Update;
  Evening Round-up;
- footer не должен создавать впечатление, что существует три разных публичных продукта; это один продукт AROUND THE MAIN с тремя ежедневными Edition.

STORY LABELS:
- автоматическая подпись карточки не должна по умолчанию становиться WORLD;
- при наличии надёжной географии используется конкретная география;
- при наличии нескольких значимых территорий допускается компактная комбинация;
- при наличии регионального масштаба используется регион;
- если география недостаточно определённая, используется editorial category;
- WORLD используется только как настоящий fallback;
- label должен оставаться коротким и читабельным.

VERTICAL LAYOUT AND PAGINATION:
- доступная вертикальная область страницы должна использоваться рационально;
- алгоритм pagination не должен оставлять необоснованно большие пустые области перед footer;
- при возможности stories должны компактно распределяться по доступной безопасной области;
- порядок stories не должен нарушаться ради заполнения страницы;
- нельзя уменьшать типографику или ухудшать читаемость только ради заполнения свободного места;
- footer должен сохранять безопасный нижний зазор;
- после изменения footer и header необходимо заново проверить page-height budget для Page 01 и Pages 02+.

MARKETS TODAY:
- утверждённая трёхстрочная структура MARKETS TODAY сохраняется;
- layout должен оставаться читаемым на мобильном формате;
- изменение публичной концепции Edition не должно менять утверждённую структуру market block.

VISUAL STYLE:
- единый газетный cream/paper background на всех страницах;
- основной цвет текста — black;
- фирменный акцент — red;
- header image сохраняет исходные пропорции;
- дизайн всех страниц должен восприниматься как один физический/цифровой выпуск;
- не допускается изменение структуры или цветовой схемы между страницами одного выпуска без редакционной необходимости;
- публичная визуальная система не должна зависеть от внутреннего времени release slot.

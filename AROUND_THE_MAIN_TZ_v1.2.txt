
31. MOBILE EDITION — PAGE LAYOUT STANDARD

Mobile Edition является постраничным представлением одного Edition.

PAGE 01:
- использует единый branded header image:
  assets/mobile-header.png;
- отдельный logo.png в верхней части страницы НЕ используется;
- header содержит фирменную визуальную идентичность AROUND THE MAIN;
- после header отображаются:
  EDITION XXXX;
  publication date;
  edition name;
  PAGE 01;
- после информационного блока начинается контент выпуска;
- в нижней части страницы располагается единый DAILY BRIEF footer.

PAGES 02+:
- branded header image НЕ используется;
- отдельный logo НЕ используется;
- в верхней части располагается компактная строка:
  edition name слева;
  PAGE XX справа;
- под строкой располагается горизонтальный divider;
- далее располагается контент страницы;
- в нижней части каждой страницы располагается тот же DAILY BRIEF footer.

PAGE NUMBER:
- номер страницы формируется динамически;
- формат:
  PAGE 01
  PAGE 02
  PAGE 03
  ...
- номер страницы не должен быть задан глобальной переменной;
- каждая страница должна получать собственный page_number.

EDITION NAME:
Название выпуска определяется типом/временем Edition.

Допустимые названия:
- Morning Briefing
- Midday Update
- Evening Round-up

Название должно автоматически использоваться на всех страницах соответствующего выпуска.

FOOTER:
- footer должен быть единообразным на всех страницах Mobile Edition;
- footer располагается в нижней части страницы;
- содержит DAILY BRIEF;
- содержит краткое описание;
- содержит GLOBAL NEWS • AROUND THE MAIN;
- содержит Telegram @aroundthemain;
- содержит X @aroundthemain;
- нижняя фирменная полоса содержит:
  STAY INFORMED. STAY AHEAD.

VISUAL STYLE:
- единый газетный cream/paper background на всех страницах;
- основной цвет текста — black;
- фирменный акцент — red;
- header image сохраняет исходные пропорции;
- дизайн всех страниц должен восприниматься как один физический/цифровой выпуск;
- не допускается изменение структуры или цветовой схемы между страницами одного выпуска без редакционной необходимости.
